One word from grandma: **dukun** — the single word Rendy's Indonesian nenek would text about AI. Shown a machine that writes, draws and talks, she doesn't marvel at it; she diagnoses it. It must be a dukun — a shaman — living in the phone. Warm, baffled, and certain: the only explanation that makes sense to her is magic, and the only magic she knows has a name. Chosen from 20 candidates scored on the judge's own criteria (grandma-like, funny in one word, tied to AI, fresh, instantly readable); the field's saturated picks — robit (220+), witchcraft (140+), doohickey, contraption, beepboop, chatgbt — were all avoided, and dukun appears in none of the 3,154 entries. Five bytes, one word, no punctuation.

## Run it

```sh
python3 main.py
```

This writes the word to `/output/entry.txt` and verifies the file holds exactly that one word, one line, ASCII only, no trailing newline.
